# Benchmarks

**Scope labels:**
- **Current measured data:** `measure`, `photos` (`10` images), and `synthetic` (`11` images) sets in `benchmarks/results.csv` (`2026-11-12`) and the 55-image research corpus in `benchmarks/corpus.csv` (`2026-11-12`), all measured with the `.fold` format version 3 <!-- drift:fact format_version = 3 --> encoder and C API 1.0 (`RF_API_VERSION_MAJOR = 1` <!-- drift:fact api_major = 1 -->, `RF_API_VERSION_MINOR = 0` <!-- drift:fact api_minor = 0 -->).
- **Historical retained data:** Pre-migration Windows measurements remain in [`docs/measurements.md`](measurements.md) with their original `2026-09-29` baseline conditions.
- **Planned scope:** native converter application benchmarks are not shown because the converter application is planned work (`docs/vision.md`) and is not yet a downloadable package.

All RasterFold size, speed, and memory figures come from committed measurement files produced by reproducible scripts in this repository:

- `benchmarks/results.csv` and `benchmarks/results.md`, generated by `tests/benchmark.py`
- `benchmarks/corpus.csv`, generated by `research/ab.py size all --csv benchmarks/corpus.csv`
