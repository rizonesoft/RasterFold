## Lessons

- In freestanding Windows builds (`-ffreestanding`), small fixed-size `memcpy(&a, p, 8u)` calls in hot loops emit out-of-line `callq memcpy` (`rep movsb`) instructions rather than single-instruction register loads; using `__builtin_memcpy` guarantees inline register loads without C runtime dependencies.
- When `rf_encode` trials both palette coding (`<= 256` colours) and context-mixing (`cm.c`) on small-palette images (`syn_stripes`), passing the palette payload size as a hard output cap (`m->cap`) into `rf_cm_encode` (gated on `m->cap < (size_t)w * h * 3u - 1u && (y & 31u) == 0u`) aborts an uncompetitive CM trial after the first 32 rows while adding zero per-row branches on `> 256`-colour images.
- Compiling extracted historical baseline sources (`cm_m1.c`) against their own extracted `m1_src/fold.c` and `-I m1_src` in `research/ab.py` preserves both Milestone 1's 7-parameter and Milestone 2's 8-parameter `rf_cm_decode` signatures without brittle source-text rewrites.
