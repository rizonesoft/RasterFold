## Lessons

- While repairing a completion gap never add, remove or reword a paragraph of the section; record the change under the completion review in the findings file. The dispatcher now refuses the reconciliation otherwise.
- A chained command must not commit under a success title after a step that can refuse: `5c99bb1` is titled as a stamp that was refused.

- Read the result line of every suite before committing, not after: a chained command that ends in `git commit` commits whatever the tests said.
- A new file that an existing document links must be added to the documentation and drift test fixtures in the same change.
- The harness refuses `rm` with a glob after a `cd`; use a fresh `mktemp -d` directory instead of clearing an old one.

- Run `python3 scripts/drift-check.py` (six seconds) before every full sweep: a forgotten receipt costs three red gates and a second eight-minute sweep.
- Never write a checkpoint sentence about evidence that does not exist yet (a CI read-back claimed before the run finished was a round finding). Quote what was read, with its run id.
- A source-only extractor is only as good as its refusals; pair it with a test against the built program, which is the actual proof.
