## Lessons

- A plan review's candidate must be the `Started` commit or its ancestor: when a section's rejection path is written after `Started`, put the rewrite in the `Started` commit (as `D01 T04 §3` did) or review the plan before recording `Started`.
- Never pipe `todo-graph.py stamp` into `tail` inside an `&&` chain: the pipe takes `tail`'s exit status, so a refused stamp commits anyway. Run it alone, or with `set -o pipefail`.
