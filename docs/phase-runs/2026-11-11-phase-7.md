## Lessons

- Never point `TEMP` or `TMP` at a Windows path for a whole command: Linux Python reads them too, and the fuzzer's worker sockets cannot be created on a drvfs path (five gates failed on it once). If Windows tools need another temp directory, set it only on their own invocation.
- A wait loop written as `pgrep -f '<pattern>'` matches the shell that runs it and never ends early; test for the process with a bracketed pattern (`ps ... | grep '[s]cripts/check-all.py'`) and for the sweep's own `exit=` line, and never start a second sweep before the first has printed it.
- On a host other sessions are using, three-thread timing pools taken minutes apart differ by more than the 10% bar on byte-identical code. Take ten rounds, read both pools, re-measure a pair that reads over the bar, and confirm single-image rows alone.

- Attribute before designing. Four Milestone 8 rounds added tokens on a guess and each grew the files; a ten-minute context simulation and a palette-entropy estimate named the two real costs, and the fifth round reached the bar.
- `tests/benchmark.py` refuses a dirty codec tree, so a size-changing section commits its port first and refreshes `benchmarks/` in a second commit of the same range.
- Windows Python writes CRLF into tracked LF files (`measure/verdict.json`, `benchmarks/results.md`); both writers now force LF.
- New C that indexes with `3 * i` on a `uint32_t` trips clang-tidy's count baseline; index through a `size_t` product.

- Ticking a checklist item makes `build/todo-progress.json` stale, and three check-all gates (plan projection, document drift, documentation site tests) fail on it. Run `python3 scripts/todo-graph.py plan --sync` after any TODO edit and before check-all; a sweep costs 6 to 12 minutes through the bosun queue.
- Renew each drift receipt with evidence written for that document; evidence copied across documents was false for the document that had changed (round 1 of D99 T01 section 9).
