## Lessons

- In `research/corpus.py`, `ic_*` photographs are cropped to `1280x960` (`h = 960`), `measure` is `1672x941` (`h = 941`), `tp_*_crop` are `1024x768` (`h = 768`), and `kodim*` are `768x512` (`18` landscape) or `512x768` (`6` portrait). Setting `choose_strips(h)` to `h >= 768 ? 3 : 1` codes the 18 landscape `768x512` Kodak images as a single continuous strip (`S = 1`) while preserving `S = 3` (`9` threads) on all `h >= 768` images (`measure`, `ic_*`, `tp_*_crop`, and portrait `kodim`).
- Never launch multiple `research/ab.py ab` timing tasks concurrently in background shells: concurrent CPU load inflates multi-threaded `-t3`/`-t9` timings by 5-10%; always run `ab.py ab -n9` sequentially on an idle machine.
