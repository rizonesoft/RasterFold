## adversarial: needs-attention

1. P2 Windows timeout cleanup leaves the smoke process alive. `tests/converter/test_bundle.py:244` times out the PowerShell parent without terminating its Windows child tree. A hung codec can survive the test, and PowerShell’s `finally` cannot guarantee cleanup after termination. 2. P1 Source verification ignores symlinks. `tools/bootstrap.py:43` excludes them from the tree digest without validating their current targets. Adding a symlink, or retargeting an existing one outside the source tree, leaves the receipt valid. Subsequent CMake configuration can consume unverified files. Include link paths and targets in verification and reject escapes on every verification pass.

3. P1 Existing RasterFold archives are never refreshed. `scripts/build-converter.py:75` invokes the core build only when the archive is absent.
