## adversarial: needs-attention

1. P1 `scripts/package.py:45` accepts any nonempty revision string and inserts it into the output path at `scripts/package.py:71`. A manifest revision such as `/../../../../outside` escapes `build/packages`; `mkdir(parents=True)` and `ZipFile(..., 'w')` can create directories and overwrite a ZIP outside the package directory. Artifact-path validation does not protect this field. Validate revision syntax and enforce destination containment.

Propagate the failure or explicitly represent unknown status.
