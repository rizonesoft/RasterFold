Catch output-validation failures, preserve the failing input and malformed output, and return an iteration-specific failure. Add a regression covering this path.

**integration: needs-attention**

1. P2 Parallel execution delays reporting hangs and continues work after failure. At `tests/fuzz_decode.py:327`, `chunksize=8` makes each worker finish eight sequential verifications before returning any result. If decoder invocations hang, the first 60-second timeout remains hidden until all eight timeouts finish, approximately eight minutes. An in-memory probe confirmed eight timeout calls before the first result became available. Returning at `tests/fuzz_decode.py:330` also exits through the executor’s blocking shutdown, which waits for running chunks. Use individually observable tasks and bounded failure shutdown so a detected hang promptly fails the campaign.
