# Reviewer-only role

Codex does not write or run campaigns in RasterFold. Use Claude Code or Antigravity to process the plan. Both writers obtain independent reviews from GPT-6 Astra through the Codex CLI using `scripts/review-dispatch.py`. Do not acquire a writer claim or start a campaign from this harness.
